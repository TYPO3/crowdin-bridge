# Project `CrowdinBridge`

[![CI](https://github.com/TYPO3/crowdin-bridge/actions/workflows/ci.yml/badge.svg)](https://github.com/TYPO3/crowdin-bridge/actions/workflows/ci.yml)
[![Extract](https://github.com/TYPO3/crowdin-bridge/actions/workflows/extract.yml/badge.svg)](https://github.com/TYPO3/crowdin-bridge/actions/workflows/extract.yml)

This project is the bridge between Crowdin and TYPO3.
The purpose is to download translations from Crowdin and copy those to the translation server.

## Setup

Run `composer install` to install the package.

## Further docs

Checkout the `docs` directory for detailed information.
